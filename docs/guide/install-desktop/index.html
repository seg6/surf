Install the desktop client

The Linux client connects to a Surf host with the same pairing and stream as the iOS one. It works on X11 and Wayland. The desktop client notes have more detail.

If you downloaded a release, follow the README inside the archive. The client keeps its identity and preferences separate from the host’s SURF_HOME.

To build from source on Debian or Ubuntu:

sudo apt-get install libasound2-dev libavcodec-dev libavformat-dev \
  libavutil-dev libgl1-mesa-dev libxkbcommon-x11-0
cargo run --manifest-path client/desktop/Cargo.toml -p surf-client
# or: make desktop-run
client/desktop/package-linux.sh   # local package

Start the host, then either enter host:port or use discovery, and pair. Check that the six words match on both screens. If you’ve saved only one server, the client reconnects to it on its own.

The tray app and surf serve are the host. The desktop client is only a remote UI and doesn’t run a browser itself.

Surf is open source under the MIT license.
