The README uses a GitHub media attachment for inline playback, not the
repository's file-preview page. The downloadable copy is 8.5 MB, H.264 at
1280×1080 and 60 fps. Its AAC audio is unchanged from the approved edit.

The walkthrough shows browsing, interactive maps, YouTube and fullscreen video,
Netflix playback, WebGL, tabs, bookmarks, and downloads. It uses the desktop
client at an iPad mini-sized portrait viewport, not filmed iOS hardware. The iOS
app has its own native interface; this recording demonstrates the shared browser
functionality, not a performance benchmark for any particular Apple device.

Interactions run at normal speed. Sound is captured from Surf client playback,
not added from the source films. Only the finished video and its poster belong
here; raw captures, browser profiles, and authentication data stay private.
