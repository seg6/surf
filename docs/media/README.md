# Surf demo

https://github.com/user-attachments/assets/5e684036-9bbf-4fce-a088-0d95dcc1a890

The demo is about 50 seconds long and has sound, so turn the sound on. You can also
[download the MP4](surf-demo.mp4?raw=true) or grab the [poster](surf-demo.jpg).

The README uses a GitHub media attachment so the video plays inline, instead of
linking to the repository's file preview page. The downloadable copy is 8.5 MB,
H.264 at 1280x1080 and 60 fps, and its AAC audio is unchanged from the approved
edit.

The walkthrough shows browsing, interactive maps, YouTube and fullscreen video,
Netflix playback, WebGL, tabs, bookmarks and downloads. It was recorded with
the desktop client at an iPad mini-sized portrait viewport, so it isn't filmed
on iOS hardware. The iOS app has its own native interface. The recording shows
the browser features the clients share, and it isn't a performance benchmark for
any Apple device.

Interactions play at normal speed. The sound comes from Surf's client playback,
not from the source films. Only the finished video and its poster live in this
folder. Raw captures, browser profiles and authentication data stay private.
