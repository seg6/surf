# Documentation

The [overview](guide/overview.md) explains what Surf is and how the pieces fit
together.

## Setting up

- Host: [install it](guide/install-host.md), then look at
  [configuration](guide/configuration.md) if you want to change anything.
- iOS: [install the client](guide/install-ios.md). The
  [iOS client notes](clients/ios.md) cover which devices work.
- Linux: [install the desktop client](guide/install-desktop.md). There are
  also [desktop client notes](clients/desktop.md).

## Using it

- [Pairing](guide/pairing.md) connects a client to your host.
- [Daily use](guide/daily-use.md) covers browsing, downloads, input and the
  clipboard.
- [Browser setup](guide/browser-setup.md) is for signing in to sites on the
  computer itself.
- [Remote access](guide/remote-access.md) covers using Surf away from home.
- [Updates](guide/updates.md) explains how the host and clients get updated.
- If something breaks, try [troubleshooting](reference/troubleshooting.md).
