Install the host

The host is the part that runs Chromium on your computer and talks to your devices. You can download a release build or compile it from source.

  • Downloads
  • Full guide

Foreground

./surf serve
surf status
surf pair

It listens for TLS connections on port 18080 by default. Keep your SURF_HOME folder when you update.
