iOS client

This is for jailbroken iPhones, iPod touches and iPads running iOS 6.0 through 14.8.1, with a rootful jailbreak. Once it's installed, pair it with the Surf host on your computer.

Add the source

https://seg6.space/surf/

  • Open in Cydia
  • Open in Sileo
  • Download .deb

In Cydia, open Sources, tap Edit, then Add, paste the URL above and install Surf. In Sileo, open Sources, tap the plus button and paste the same URL. If the icon doesn't show up after installing, respring.
