Surf

Remote browser on hardware you already have

Surf runs Chromium on a Windows, macOS, or Linux computer and streams that page to a native app. The app draws the chrome (tabs, address bar, library) and sends input back. Page content never goes through the device's own web engine.

  • Install the host
  • iOS client
  • Linux client

How it works

The host owns a Chromium profile: cookies, JavaScript, downloads, and site sign-in all happen there. The client opens a pinned TLS connection, shows the live stream, and forwards touch, keyboard, pointer, and files. You pair once with a QR code or a short code, then confirm the six words match on both ends.

Surf is not a hosted service. There is no account and no shared password. Run the host on your LAN, or on any address the client can reach. Each device keeps its own key. Clients pin the host certificate and refuse a different fingerprint.

In practice

Chromium does the browsing

You get whatever that desktop Chromium can load. For awkward logins, open Browser setup on the computer, finish there, then continue from the client.

The client is a browser UI

Tabs, suggestions, bookmarks, history, downloads, find, and reader are built into the app. It is not a full-desktop remote-desktop session.

Data stays on the host

Identity, pairings, and the browser profile live under SURF_HOME. Revoke a device from the host when you want it gone.
