Surf Modern web, classic iOS

iOS client / version 0.13.7

Put the modern web on this screen.

Surf streams a current Chromium browser from your computer to this iPhone or iPad.

Add the Surf repository

Use Cydia on iOS 6–10. Sileo is offered for supported newer jailbreaks.

1 Add the source

Tap the button above, or paste the source URL into your package manager.

2 Install Surf

Search for Surf, install it, then let the device respring if requested.

3 Pair your device

Run Surf on a computer, choose Pair device, and scan its QR code.

Requires a compatible rootful jailbreak and a 64-bit Windows, macOS, or Linux computer running Surf. This page and Cydia path are compatible with iOS 6 Safari; Sileo itself requires a newer iOS version.
