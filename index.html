Surf

A modern browser for devices that can't run one anymore

Surf runs Chromium on a computer and streams it to a native app on another device. The app works like a regular browser, with tabs, an address bar, bookmarks and history, while pages load and run in Chromium on the computer.

  • Install the host
  • iOS client
  • Linux client

How it works

The host program on your computer keeps its own Chromium profile, so cookies, JavaScript, downloads and site sign-ins all live there. The app on your other device connects over TLS, shows the live stream, and sends your touch, keyboard and pointer input back, along with any files you upload. You pair the two once, with a QR code or a short code, and check that the same six words show up on both screens.

There is no hosted service and no account. The host runs on your home network, or at any address your device can reach. Each device has its own key, and each client remembers the host's certificate and refuses to connect if it changes.

Using Surf

Page compatibility

Websites see an up-to-date desktop Chromium, so pages that no longer load on an old device work again. If a site has trouble with signing in through the stream, open Browser setup on the computer, sign in there, and continue from your device.

Browser interface

Tabs, suggestions, bookmarks, history, downloads, find and a reader view are built into the app. It shows the browser only, not the whole desktop.

Data storage

Pairings and the browser profile are stored in SURF_HOME on the computer. To remove a device, revoke it from the host.

Clients

iOS / iPadOS 6-14

The iOS client is a jailbreak package for iOS 6 through 14 and installs from Cydia or Sileo. The steps are on the iOS page.

Linux

A desktop client that pairs with the host the same way the iOS app does.

PS Vita (community port)

A port of the shared client core, maintained in its own repository.
